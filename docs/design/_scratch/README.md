# _scratch/

Local-only space for non-canonical design experiments — draft mockups, AI-generated explorations, screenshots, and anything else that hasn't been promoted to a canonical artifact yet.

The folder itself is tracked (via this `README.md`); the contents are gitignored. If you produce something worth keeping, move it to `../hybrid-premium-canvas/` and follow the numbering scheme described there.

Do not import anything from this folder into product code.
